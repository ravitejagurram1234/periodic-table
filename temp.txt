1. Column data-type report (the practical one)

Clean per-column list — e.g. ID_STRUCTURE VARCHAR2(20), INPUT_DATA_TYPE NUMBER(2,0):
SELECT table_name,
       column_id,
       column_name,
       CASE
         WHEN data_type IN ('VARCHAR2','CHAR','NVARCHAR2','NCHAR')
              THEN data_type || '(' || char_length || ')'
         WHEN data_type = 'NUMBER' AND data_precision IS NOT NULL
              THEN 'NUMBER(' || data_precision || NVL2(data_scale, ',' || data_scale, '') || ')'
         ELSE data_type
       END AS data_type,
       nullable                     -- N = NOT NULL, Y = nullable
FROM all_tab_columns
WHERE owner = 'QXP'
ORDER BY table_name, column_id;
For one table (e.g. the one you're checking): add AND table_name = 'QXP_IMPORT_LUX'.
(Table/owner names are UPPERCASE in the dictionary. If you're logged in as QXP, you can swap all_tab_columns/owner='QXP' for user_tab_columns and drop the owner filter.)

2. Full CREATE TABLE DDL (DBMS_METADATA)

-- optional: make the DDL clean (no storage/tablespace clutter) — run once per session
BEGIN
  DBMS_METADATA.SET_TRANSFORM_PARAM(DBMS_METADATA.SESSION_TRANSFORM,'STORAGE',FALSE);
  DBMS_METADATA.SET_TRANSFORM_PARAM(DBMS_METADATA.SESSION_TRANSFORM,'SEGMENT_ATTRIBUTES',FALSE);
  DBMS_METADATA.SET_TRANSFORM_PARAM(DBMS_METADATA.SESSION_TRANSFORM,'TABLESPACE',FALSE);
  DBMS_METADATA.SET_TRANSFORM_PARAM(DBMS_METADATA.SESSION_TRANSFORM,'SQLTERMINATOR',TRUE);
END;
/

SELECT DBMS_METADATA.GET_DDL('TABLE', table_name, owner) AS ddl
FROM   all_tables
WHERE  owner = 'QXP'
ORDER  BY table_name;
GET_DDL returns a CLOB. In SQL Developer / IntelliJ it displays fine (click to expand). In SQL*Plus first run: SET LONG 2000000 PAGESIZE 0 LINESIZE 32767 LONGCHUNKSIZE 200000.

3. Foreign keys (what ora.txt can't show — e.g. QXP_RUN.ID_DOC_*, ID_SUIVI)

SELECT ac.table_name,
       acc.column_name,
       ac.constraint_name,
       r.table_name  AS references_table,
       rcc.column_name AS references_column
FROM   all_constraints ac
JOIN   all_cons_columns acc ON acc.owner = ac.owner AND acc.constraint_name = ac.constraint_name
JOIN   all_constraints r    ON r.owner = ac.r_owner AND r.constraint_name = ac.r_constraint_name
JOIN   all_cons_columns rcc ON rcc.owner = r.owner AND rcc.constraint_name = r.constraint_name
                            AND rcc.position = acc.position
WHERE  ac.owner = 'QXP' AND ac.constraint_type = 'R'
ORDER  BY ac.table_name, ac.constraint_name, acc.position;

Handy extras

- Just the tables list: SELECT table_name FROM all_tables WHERE owner='QXP' ORDER BY table_name;
- PK / unique / check constraints: same as #3 but constraint_type IN ('P','U','C') (drop the r/rcc joins).
